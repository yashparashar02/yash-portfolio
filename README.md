# Yash Parashar Portfolio

A modern developer portfolio built using React, Vite and Tailwind CSS.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion (Motion)
- React Icons

## Features

- Responsive Design
- Smooth Animations
- Mobile Navigation
- Experience Timeline
- Projects Showcase
- Skills Grid
- Education
- Professional Development
- Contact Section

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
